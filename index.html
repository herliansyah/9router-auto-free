Panduan Penggunaan 9router Auto-Free

Semua hal yang perlu Anda ketahui: fungsi, cara kerja, dan tutorial integrasi ke IDE.

💡 Apa itu 9router Auto-Free?

9router Auto-Free adalah sistem otomasi cerdas yang mengumpulkan ratusan model AI gratis dari berbagai provider terkemuka (OpenAgentic, Kilo.ai, OpenRouter, Google Gemini, Groq, Mistral, Cerebras, Ollama, dll.), menguji model-model tersebut secara langsung lewat Live Pre-Test, menyaring model rusak/berbayar/kuota habis, lalu mengurutkannya berdasarkan skor kapabilitas coding riil serta latensi tercepat.

Hasil akhirnya disuntikkan secara otomatis ke dalam Combo 9router (seperti my9model-free), sehingga Anda cukup memakai satu nama model di IDE tanpa repot mencari atau menggonta-ganti API key gratisan.

Bagaimana Cara Kerjanya? (6 Tahap Otomatis)

1. Scrape & Kumpul Kandidat

Mengambil daftar model gratis dari 15+ sumber provider terdaftar (OpenAgentic, Kilo, Gemini, OpenRouter, Groq, dll.).

2. Filter Exclusions

Menyaring dan membuang model non-coding (TTS, embed, video, model terlalu kecil/nano) dan provider yang di-blacklist.

3. Live Pre-Test Paralel

Setiap kandidat dites langsung melalui endpoint internal 9router untuk mengukur latensi dan status HTTP asli.

4. Vonis & Auto-Cooldown

Model 200 diterima; model kuota habis (429) diparkirkan di my9model-cooldown; model berbayar/mati dibuang.

5. Coding Quality Ranking

Model diurutkan berdasarkan skor benchmark coding empiris (EvalPlus, SWE-bench), dikurangi penalti error-rate, dan latensi.

6. Injeksi Database 9router

Daftar model langsung ditulis ke database SQLite 9router. IDE Anda langsung otomatis menikmati daftar model terbaru.

Daftar Combos & Rekomendasi Penggunaan

my9model-free Super Combo Utama

Kombinasi seluruh model gratis aktif dari semua provider. Urutan teratas adalah model dengan kemampuan coding terbaik dan latensi tercepat.

👉 Pilihan terbaik untuk penggunaan umum harian di IDE.
my9model-smart Penalaran Tinggi / Reasoning

Khusus model thinking/reasoning (misal Claude 3.7 Sonnet Thinking, Qwen Coder, DeepSeek R1) atau model dengan benchmark coding tertinggi.

👉 Cocok untuk tugas arsitektur rumit, refactor besar, dan debug bug sulit.
my9model-fast Super Cepat / Low Latency

Model non-thinking berkecepatan kilat dengan latensi sangat rendah dari provider berkecepatan tinggi (Groq, Cerebras, Kilo, dll.).

👉 Cocok untuk inline code completion, autocomplete, atau respons instan.
my9model-cooldown Parkiran Rate-Limit (429)

Tempat isolasi sementara bagi model yang kuota hariannya habis (HTTP 429). Watchdog intra-hari akan otomatis memindahkannya kembali ke combo utama begitu kuota reset.

👉 Mencegah IDE Anda error karena request terlempar ke model kuota-habis.

Pertanyaan Umum (FAQ)

Q: Mengapa port web console ini 20129 padahal 9router di 20128?

Port 20128 digunakan oleh server Next.js & API endpoint utama 9router. Oleh karena itu, Web Console Auto-Free berjalan di port 20129 agar dapat berjalan berdampingan tanpa konflik port.

Q: Bagaimana jika kuota salah satu model gratis habis di tengah hari?

9router secara otomatis akan melakukan fallback (mengalihkan request) ke model urutan berikutnya di dalam combo. Selain itu, fitur Watchdog yang berjalan tiap jam akan mendeteksi HTTP 429 dan memindahkan model tersebut ke my9model-cooldown agar tidak dipanggil lagi sampai kuotanya reset.

Q: Apakah password dashboard ini aman?

Sangat aman. Dashboard ini memverifikasi password langsung menggunakan pencocokan hash bcrypt dari database SQLite 9router Anda sendiri. Tidak ada password atau kredensial yang dikirim ke server luar.

Q: Bagaimana jika lokasi instalasi 9router saya bukan default (Custom Dir / Docker / Windows)?

Aplikasi ini otomatis mendeteksi lokasi 9router di Linux/macOS (~/.9router), Windows (%APPDATA%/9router), dan Docker (/app/data). Jika Anda menggunakan lokasi kustom lain, Anda bisa menentukannya melalui:

  • Environment Variable: export NINEROUTER_DIR="/custom/path"
  • Database Path: export NINEROUTER_DB_PATH="/custom/path/db/data.sqlite"
  • URL / Port Custom: export NINEROUTER_URL="http://127.0.0.1:20128"
  • CLI Flag: node web.js --nine-router-dir="/custom/path"
Q: Apakah provider baru di luar list bawaan bisa langsung disinkronkan tanpa ubah kode?

Bisa langsung 100%! Sistem memiliki Generic Dynamic Provider Engine. Semua provider OpenAI-compatible baru (DeepSeek, SiliconFlow, Together AI, Fireworks, Ollama, Custom Node, dll.) yang Anda pasang di 9router akan otomatis ditarik daftar modelnya, diuji via live pre-test, dan diinjeksi ke combo super serta combo provider. Anda juga dapat mengatur tombol toggle Auto-Sync Free untuk mengaktifkan/menonaktifkan sync per provider secara instan.

Q: Bagaimana cara setup penjadwalan otomatis (scheduler) jika saya menginstall dari NPM?

Ada 2 cara yang sangat praktis:

  • Via Web UI (1-Klik): Buka tab 💻 CLI Ops lalu klik tombol Setup Scheduler.
  • Via NPX: Jalankan npx 9router-auto-free --setup-cron di terminal.
  • Via Global NPM: Jalankan 9router-auto-free --setup-cron di terminal.
